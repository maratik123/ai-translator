# Frontend: архитектура

## Стек
Vite, React, TypeScript, Zustand (стейт), типы из `src/generated/` (ts-rs). Без UI-фреймворка на старте, CSS modules или Tailwind по вкусу.

## Экраны
1. **Библиотека**: список книг, загрузка файла, прогресс перевода по каждой книге, кнопка «перевести целиком».
2. **Читалка**: две колонки, оглавление, позиция, настройки шрифта, индикатор статуса модели.
3. **Настройки**: URL llama-server, модель, языки, размер окна префетча, редактор промпта (для экспериментов).

## Структура (`frontend/src`)
```
generated/         типы из ts-rs (не редактировать)
api/
  ws.ts            подключение, реконнект, RPC с request_id, подписка на события
  http.ts          upload, URL картинок
store/
  library.ts       книги и статусы
  reader.ts        текущая книга, глава, абзацы, переводы, позиция
  settings.ts
reader/
  ReaderView.tsx   контейнер двух колонок
  Column.tsx       рендер списка абзацев (виртуализация по главе)
  useSync.ts       синхронизация прокрутки/выравнивание по абзацам
  usePosition.ts   определение текущего абзаца (IntersectionObserver), отправка позиции
library/
settings/
```

## Читалка: раскладка
- Единица рендера: абзац. Обе колонки рендерят один и тот же список id, слева `html` оригинала, справа перевод (или плейсхолдер «переводится»).
- Выравнивание: каждая пара абзацев это одна строка CSS grid `grid-template-columns: 1fr 1fr`, высота строки по большему из двух. Так колонки не разъезжаются и не нужен ручной scroll-sync.
- Прокрутка непрерывная внутри главы, переход между главами по кнопке или при достижении края.
- Текущий абзац определяется IntersectionObserver по верхней трети экрана; позиция отправляется на бэк с дебаунсом 500 мс.
- Переносы: `hyphens: auto` с `lang` на колонках (`lang="en"` / `lang="ru"`).

## Поток событий WS
- `OpenBook` → ответ с главами и позицией.
- `LoadChapter(n)` → абзацы + имеющиеся переводы.
- `SetPosition(paragraph_id)` → без ответа.
- Входящие: `ParagraphTranslated`, `TranslationFailed`, `ContextCompacted`, `LlmStatus`, `BookProgress`.

## Состояние
`reader` store хранит `Map<paragraph_id, Translation>`; событие `ParagraphTranslated` обновляет одну запись, React перерисовывает одну строку grid.

## Оффлайн и реконнект
При обрыве WS фронт показывает баннер и реконнектится с экспоненциальной задержкой; после реконнекта переоткрывает книгу и текущую главу (идемпотентно).
