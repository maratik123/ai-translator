# 02. Импорт книг (epub, fb2)

## Задачи
- [ ] `POST /api/books`: multipart, лимит размера, определение формата по расширению и magic bytes.
- [ ] epub: распаковка ZIP, `META-INF/container.xml` → OPF → spine → XHTML-файлы по порядку. Крейт `epub` для старта, свой парсер, если не хватит.
- [ ] fb2: `quick-xml`, `<body>` → `<section>` → `<p>`; картинки из `<binary>`.
- [ ] Сегментация: XHTML главы → список абзацев. Блочные элементы (`p`, `h1..h6`, `li`, `blockquote`, `pre`) становятся абзацами, inline-разметка (`em`, `strong`, `a`) сохраняется в `html`, чистый текст кладется в `text`.
- [ ] Стабильные id абзацев: `hash(book_id, chapter_index, paragraph_index, text)`; при повторном импорте той же книги переводы переиспользуются.
- [ ] Картинки и CSS: сохранить в `assets/` рядом с БД, переписать `src`/`href` на `/api/books/{id}/assets/...`.
- [ ] Обложка: из OPF `cover-image`, иначе первая картинка.
- [ ] Определение языка книги: метаданные, иначе `whatlang` по первым 2000 словам.

## Крайние случаи
- Очень длинные абзацы (>2000 символов): делить по предложениям на подабзацы с суффиксом в `index`, иначе модель теряет предложения.
- Абзацы без текста (только картинка): `kind = image`, перевод не запрашивается.
- Сноски и ссылки: переводятся как обычные абзацы, якоря сохраняются.
- Неправильный XHTML: парсить `html5ever`, не строгим XML.
