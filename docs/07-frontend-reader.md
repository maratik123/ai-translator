# 07. Фронт: читалка

## Задачи
- [ ] Каркас Vite + React + TS, Zustand, генерированные типы подключены.
- [ ] `ReaderView`: CSS grid двух колонок, строка = пара абзацев, sticky-шапка с названием главы и прогрессом.
- [ ] Рендер `html` абзаца через `dangerouslySetInnerHTML` после санитизации (`DOMPurify`, whitelist inline-тегов).
- [ ] Плейсхолдер перевода: скелетон нужной высоты (оценка по длине оригинала), чтобы строка не прыгала при появлении перевода.
- [ ] `usePosition`: IntersectionObserver, первый абзац, пересекающий линию на 30% высоты экрана, дебаунс 500 мс → `SetPosition`.
- [ ] Восстановление позиции при открытии: `scrollIntoView` на сохраненный абзац после рендера главы.
- [ ] Навигация: оглавление в боковой панели, клавиши ← → для глав, `PageDown/PageUp`.
- [ ] Настройки отображения: шрифт, кегль, ширина, темная тема (persist в localStorage).
- [ ] Виртуализация: `@tanstack/react-virtual` по строкам grid, если глава > 300 абзацев тормозит. Сначала без нее.
- [ ] Режим «только оригинал / только перевод» для проверки чтения.
